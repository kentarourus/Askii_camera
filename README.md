# ASCII VISION - リアルタイム アスキーアート カメラアプリ 📸

Webカメラの映像や画像をリアルタイムで美しい**アスキーアート（ASCII Art）**に変換・描画する、モダンで高精度なWebアプリケーションです。

## ✨ 主な機能

### 1. 🎥 リアルタイムカメラ & メディア入力
- **Webカメラ変換**: お使いのPC・スマートフォンのWebカメラ映像をリアルタイムでアスキーアート化。
- **カメラ切り替え**: インカメラ（前面）/ アウトカメラ（背面）の切り替えに対応。
- **ファイル読み込み & ドラッグ＆ドロップ**: 手持ちの画像ファイル（PNG, JPG, GIFなど）や動画ファイルをドラッグ＆ドロップで変換可能。

### 2. 🎨 多彩なカラー＆カスタムテーマ
- **Matrix Green**: サイバーパンクな『マトリックス』風グリーンモニター。
- **Cyber Neon**: シアンとピンクの煌びやかなネオンカラーグラデーション。
- **Full Color**: 元画像のRGBカラーを忠実に再現したフルカラーアスキーアート。
- **Monochrome**: クラシックな白黒アスキーアート。
- **Amber CRT**: レトロなアンバー液晶ディスプレイ風。
- **Inverted**: 背景が白、文字が黒のネガポジ反転モード。
- **Custom Color**: 自由な背景色（Background Color）と文字色（Text Tint Color）をカラーピーカーで指定可能。

### 3. 🔤 自由な文字セット
- **Standard**: `@%#*+=-:. ` （バランスの良い8階調）
- **Detailed**: 70階調の超高精細アスキー文字セット
- **Matrix**: `ｦｱｳｴｵｶｷｹｺｻｼｽｾｿ...` （カタカナ＆数字のサイバー文字）
- **Blocks**: `█▓▒░ ` （立体ブロック表現）
- **Binary**: `10` （バイナリ表現）
- **Emoji**: `💥🔥😎⭐✨` （絵文字レンダリング）
- **Custom**: ユーザーが自由な文字シーケンスを入力可能。

### 4. 🎛️ 詳細な画像・色彩パラメータ調整 (Fine-Tuning)
- **鮮やかさ (Saturation)**: `0.0` (完全グレースケール) 〜 `3.0` (超高彩度)
- **ガンマ補正 (Gamma)**: 中間トーンの明暗度バランス調整 (`0.2` 〜 `2.5`)
- **輪郭抽出 (Edge Detection)**: エッジ強調モード（輪郭感度スライダー調整付き）
- **明るさ & コントラスト**: リアルタイムで輝度やコントラストを補正。
- **文字縦横比 (Aspect Ratio)**: 文字の歪みを抑えるアスペクト比調整。
- **FPS表示**: リアルタイムパフォーマンス（FPS）のインジケーター表示。

### 5. 💾 多彩な保存＆共有オプション
- **PNG画像で保存**: アスキーアート描画キャンバスをそのまま高解像度PNG画像として保存。
- **テキスト (.txt) 保存**: アスキーアートテキストデータとして保存。
- **クリップボードへコピー**: テキストとしてワンクリックでコピー可能。
- **全画面表示 & 一時停止**: ビューアの一時停止/再開、フルスクリーン表示に対応。

## 🚀 使い方 / 起動方法

### 前提条件
- Node.js (v16以上推奨)

### インストール & 開発サーバー起動

```bash
# 開発サーバーの起動
npm run dev
# または
npx vite
```

起動後、ブラウザでアクセスしてください。

### 生産用ビルド

```bash
npm run build
```
