# ASCII VISION - リアルタイム アスキーアート カメラアプリ 📸

Webカメラの映像や画像をリアルタイムで美しい**アスキーアート（ASCII Art）**に変換・描画する、モダンで高機能なWebアプリケーションです。

## ✨ 主な機能

### 1. 🎥 リアルタイムカメラ & メディア入力
- **Webカメラ変換**: お使いのPC・スマートフォンのWebカメラ映像をリアルタイムでアスキーアート化。
- **カメラ切り替え**: インカメラ（前面）/ アウトカメラ（背面）の切り替えに対応。
- **ファイル読み込み & ドラッグ＆ドロップ**: 手持ちの画像ファイル（PNG, JPG, GIFなど）や動画ファイルをドラッグ＆ドロップで変換可能。

### 2. 🎨 多彩なカラー＆スタイルモード
- **Matrix Green**: サイバーパンクな『マトリックス』風グリーンモニター。
- **Cyber Neon**: シアンとピンクの煌びやかなネオンカラーグラデーション。
- **Full Color**: 元画像のRGBカラーを忠実に再現したフルカラーアスキーアート。
- **Monochrome**: クラシックな白黒アスキーアート。
- **Amber CRT**: レトロなアンバー液晶ディスプレイ風。
- **Inverted**: 背景が白、文字が黒のネガポジ反転モード。

### 3. 🔤 自由な文字セット
- **Standard**: `@%#*+=-:. ` （読みやすくバランスの良い8階調）
- **Detailed**: 70階調の高精細なアスキー文字セット
- **Blocks**: `█▓▒░ ` （ドット絵・ブロック表現）
- **Binary**: `10` （バイナリ・マトリックスコード表現）
- **Emoji**: `💥🔥😎⭐✨` （絵文字を使ったユニークなレンダリング）
- **Custom**: ユーザーが自由な文字シーケンスを入力可能。

### 4. 🎛️ 細かな画像＆解像度調整
- **解像度 (Columns)**: アスキーアートのグリッド細かさを自由にスライダー調整。
- **フォントサイズ**: フォント描画サイズ（px）の変更。
- **明るさ & コントラスト**: リアルタイムで輝度やコントラストを補正。
- **輝度反転**: 明暗を反転させてアートの雰囲気を一変。

### 5. 💾 多彩な保存＆共有オプション
- **PNG画像で保存**: アスキーアート描画キャンバスをそのまま高解像度PNG画像として保存。
- **テキスト (.txt) 保存**: アスキーアートテキストデータとして保存。
- **クリップボードへコピー**: テキストとしてワンクリックでコピー可能。
- **全画面表示 & 一時停止**: ビューアの一時停止/再開、フルスクリーン表示に対応。

## 🚀 使い方 / 起動方法

### 前提条件
- Node.js (v16以上推奨)

### インストール & 開発サーバー起動

```bash
# プロジェクトのディレクトリに移動
cd Askii_camera

# 開発サーバーの起動
npm run dev
# または
npx vite
```

起動後、ターミナルに表示されたローカルURL（例: `http://localhost:5173`）にブラウザでアクセスしてください。

### 生産用ビルド

```bash
npm run build
```

`dist` ディレクトリに最適化された静的ファイルが出力されます。

## 📁 ディレクトリ構造

```

├── index.html          # メインHTML・UI構造
├── style.css           # サイバーパンク・ガラスモルフィズムデザインCSS

├── asciiEngine.js      # アスキーアート変換＆描画コアエンジン

└── package.json        # プロジェクト設定およびスクリプト
```

## 🛠️ 使用技術

- **HTML5 & Canvas API**: リアルタイムのピクセル解析および高速テキスト描画
- **Vanilla JavaScript (ES Modules)**: 外部ライブラリ非依存の軽量かつ高速なモジュール構成
- **CSS3 Variables & Glassmorphism**: モダンで洗練されたダークテーマデザイン
- **Vite**: 高速な開発環境・ビルドツール
